## 答疑 CLI 材料（为什么这么做 / 长什么样）

| 文件 | 用途 | 说明 |
|---|---|---|
| `组件选型解析.md` | **从"要展示什么"倒推"用什么组件"**，6 个展示需求逐个选型 + 候选对比 | 解释"为什么用 el-table 而不是 el-card"这类选型决策 |
| `原型-流程管理页.html` | 这页的**静态原型预览**，双击用浏览器打开 | 手工复刻 Element Plus 外观（深色侧栏+顶栏+表格页），看布局与组件形态用 |

### 原型 HTML 的定位（重要）

- 它是**预览用**的静态页，用普通 `<table>`/`<div>` + 内联 CSS 手工仿照 EP 外观，**自包含、无需联网**。
- 它**不是** Vue + Element Plus 的真实写法，**别当 `index.vue` 的代码参照**——真实写法看 `03-完整代码.md`。
- 用途区分：原型 HTML = "看长相"；文档 03 = "照着写"。
- 颜色/圆角/间距是近似，最终以 `npm run dev` 实跑为准。

## 工作流说明

这些答疑材料产自「双 CLI 工作流」（见仓库根 `../../双CLI工作流.md`）：
主 CLI 负责改代码，答疑 CLI 只读、讲原理、做预览，不改业务代码。
