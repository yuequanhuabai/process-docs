# UI 配色规律与深色侧栏方案

> 用途：记录本项目配色背后的**可复用规律**，而不只是"用了哪几个色号"。
> 以后做用户 / 流程 / 待办等页面时，按这套规律配色即可保证「和谐 + 清晰 + 有焦点」。
> 落地位置：侧栏配色见 `src/layout/index.vue`。

---

## 一、三个目标，三种手法

配色时同时要满足三件事，各有对应手法：

| 目标 | 手法 | 一句话 |
|---|---|---|
| **看得清**（可读性） | 拉开**明暗差** | 文字与背景的「亮度」要差得够多 |
| **不打架**（和谐） | 用**同一色相**、只改明暗 | 非重点元素都从一个颜色派生 |
| **能凸显**（焦点） | 用**对比色相 + 高亮度**当强调色 | 只给「当前选中/主操作」一个跳出来的颜色 |

> **核心洞察**：决定「看不看得清」的主要是**明暗（亮度）差**，不是色相差。
> 反例——默认深色文字压在深色侧栏上：两者色相不同（灰 vs 蓝），但**亮度都低**，于是糊成一团、几乎不可见。这正是「深色侧栏套用浅色默认样式」翻车的原因（Element 默认菜单色是给**浅色侧栏**设计的）。

## 二、本项目深色侧栏方案（4 色拆解）

整套 = **一个色相的明暗阶梯　+　一个强调色**：

```
蓝灰色相家族（同一个颜色，只调亮度）：
  #304156   侧栏底色        —— 暗（亮度低）
  #263445   悬停/选中背景   —— 更暗一档（同色相再压暗）
  #bfcbd9   普通文字        —— 很亮（同色相拉到最亮端）

强调色（唯一一个不同色相）：
  #ffd04b   选中项文字      —— 暖金色（冷蓝的对面）
```

| 色号 | 用途 | 为什么这样选 |
|---|---|---|
| `#304156` | 侧栏底色 | 去饱和的深蓝灰，比纯黑柔和、显专业 |
| `#263445` | 悬停 / 选中项背景 | 底色**再压暗一档**、同色相 → 选中项像「陷下去」，自然不突兀 |
| `#bfcbd9` | 普通菜单文字 | 与底色**同家族、亮度相反**（底暗字亮）→ 明暗差拉满，清晰又不刺眼（比纯白 `#fff` 柔和不晃眼） |
| `#ffd04b` | 选中项文字（强调色） | 侧栏是**冷色(蓝)**，金是**暖色**，冷暖近乎色轮相对 → 对比最强；再加高亮度 = 一眼定位「当前在哪」 |

**为什么不用 Element 主蓝 `#409eff` 当选中色？** 它与蓝灰侧栏**同属冷色**，凸显不足；换暖金 `#ffd04b`，冷暖对撞才够跳。这就是「对比色相」的价值。

## 三、可复用配方（做任何页面都套这三步）

1. **定一个主色相**：背景、悬停、边框、普通文字**都从它派生**，只改明暗、不换色相 → 保证「整体和谐、不影响原有风格」。
2. **只留一个强调色**：给「必须被注意」的东西（选中项、主按钮、报警数字）。要求：**色相与主色相拉开**（最好冷暖相对）+ **亮度够高**。用得越省，焦点越明确；强调色一多就变噪音。
3. **靠明暗差保可读**：正文与背景亮度差要够开。业界标准 **WCAG 对比度**，正文建议 **≥ 4.5:1**。（`#bfcbd9` 配 `#304156` 约 7:1，安全）

**一句话总纲**：
> 大面积用「一个色相的明暗层次」保和谐，小面积用「一个对比色相」抢焦点，靠「明暗差」保清晰。

## 四、实操技巧

- **用 HSL 想颜色**，别用十六进制：固定 `H`(色相)、`S`(饱和度)，只调 `L`(亮度)，就能生成「同色相明暗阶梯」；找强调色就把 `H` 转到对面（如蓝 ~210° → 暖黄 ~45°）。
- **验证清晰度**：搜任意 "contrast checker" 在线工具，填两个色即得对比度比值，正文 ≥ 4.5:1 即达标。
- **改 Element 组件内部状态样式要靠 `:deep()`**：`background-color` 等属性只管整体底色，管不到「悬停 / 选中」这类组件**内部**状态（`.el-menu-item.is-active`），`scoped` 样式够不着，须 `:deep()` 穿透。

## 五、落地代码（`src/layout/index.vue`）

`el-menu` 自带三个专为深色侧栏准备的属性：

```vue
<el-menu
  :default-active="$route.path"
  router
  background-color="#304156"
  text-color="#bfcbd9"
  active-text-color="#ffd04b"
>
  <el-menu-item v-for="m in menus" :key="m.index" :index="m.index">
    {{ m.title }}
  </el-menu-item>
</el-menu>
```

属性覆盖不到的「悬停 / 选中背景」，用 `:deep()` 穿透补：

```scss
:deep(.el-menu) {
  border-right: none;
}
// 鼠标悬停 / 当前选中项：加深一点背景，让它从侧栏里"浮"出来
:deep(.el-menu-item:hover),
:deep(.el-menu-item.is-active) {
  background-color: #263445;
}
```

| 改法 | 用在哪 | 特点 |
|---|---|---|
| **组件属性**（`text-color`/`active-text-color`/`background-color`） | 写在 `<el-menu>` 标签上 | Element 为「深色侧栏」留的口子，最省事、可读性好 |
| **`:deep()` 穿透 CSS** | `<style>` 里 | 属性覆盖不到的细节（悬停/选中背景等）靠它进组件内部改 |
